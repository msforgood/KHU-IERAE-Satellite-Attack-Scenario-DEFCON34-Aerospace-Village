CCSDS command packet, layer by layer

Prototype for Phase 4. How the ground-station uplink is built, one layer at a time, with each field's size and where its value comes from.

Two layers. The command you solve is a Space Packet (SPP, CCSDS 133.0-B), the 38-byte block on the left below. To actually send it, the ground station wraps it in a TC Transfer Frame (TF, CCSDS 232.0-B): a 5-byte link header in front and a 2-byte error check at the end. So the full uplink is TF { header + Space Packet + FECF } = 45 bytes.
Fictional IDs. CCSDS defines the packet structure, not the values for an orbit-maneuver command. The Spacecraft ID (SCID), APID, Virtual Channel and cFS function code are all assigned per mission (SANA or the mission ICD), never per command type. This demo uses made-up values for the fictional ENIGMA-1 (SCID 200, APID 0x1F0, function code 0x03).
